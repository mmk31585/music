# Muse — Learnings Log

> Append-only log of non-trivial bugs, surprises, and fixes discovered during development.

| Date | Symptom | Cause | Fix | Rule |
|------|---------|-------|-----|------|
| 2026-10-15 | Frontend build fails with "Error parsing JavaScript expression: Unexpected token" in multiple Vue files | Multi-line JavaScript expressions in `@click` handlers (e.g., `@click="var = value; other = value"`) are not valid in Vue templates | Extract multi-line expressions to methods in `<script setup>` and call the method from template (e.g., `@click="handleClick()"`) | Vue template expressions must be single-line; use methods for complex logic |
| 2026-10-15 | Frontend build fails with "Illegal '/' in tags" in SearchOverlay.vue | Text interpolation `{{ suggestion }}` was placed as an attribute on the button element instead of as child content | Move `{{ suggestion }}` between opening and closing button tags | Vue template syntax: content goes between tags, attributes go on opening tag |
| 2026-10-15 | Frontend build fails due to template syntax errors in 5 files | Multiple Vue files had multi-line expressions in event handlers | Fixed all 5 files by extracting to methods | Run `npm run build` early to catch template syntax errors || 2026-10-15 | Import cycle between auth and permissions packages | Auth middleware imported permissions for role hierarchy lookup, permissions imported auth for auth middleware | Refactored to use hierarchy fetcher function pattern and context keys | Break import cycles by using function interfaces and context keys instead of direct package imports |
| 2026-10-19 | Recommendation worker logs `recommendation generation failed` every 5 min | `refreshUserAffinities` used `COUNT(*) * CASE WHEN lh.completed ...` — `lh.completed` is neither grouped nor aggregated (SQLSTATE 42803) | Replaced with `SUM(CASE WHEN lh.completed THEN 1.0 ELSE 0.3 END)` | In an aggregate query, every non-grouped column must be wrapped in an aggregate function — `COUNT(*) * CASE WHEN col ...` is not valid |
| 2026-10-19 | Analytics play counts inflated on every worker run | `analytics` worker re-added a rolling 24h window to `track/artist/album_analytics` columns that the event-driven analytics module already increments (`+ EXCLUDED`) | Removed the redundant worker aggregation (keep real-time counts); made `creator_daily_stats` idempotent (replace) | A counter must have exactly one writer — never let a periodic job re-add to a column an event handler already increments |
| 2026-10-19 | Duplicate/double side effects from outbox consumers (api + worker) | `FOR UPDATE SKIP LOCKED` executed outside an explicit transaction holds no lock, so two consumers can both read the same row | Wrap select + side effect + mark in one transaction | `FOR UPDATE SKIP LOCKED` only locks for the duration of the enclosing transaction; a bare statement's implicit tx ends immediately |
| 2026-10-19 | Browser WebSocket rejected: `request origin not allowed by Upgrader.CheckOrigin` | WS upgrader validates against `CORS_ALLOWED_ORIGINS`; the deployed LAN origin was not listed | Added the LAN origin to `CORS_ALLOWED_ORIGINS` | WebSocket origin checks reuse the CORS allow-list — a non-listed origin breaks realtime features even though HTTP works |
| 2026-10-19 | Outbox grew without bound; events re-delivered forever | The relay re-published via `Bus.Publish`, which inserts a new outbox row each pass | Relay dispatches without persisting (`Bus.Dispatch`); `Publish` marks its own row processed | Recovery/replay paths must dispatch only — never re-persist the event they are replaying |
| 2026-10-19 | Admin `enrich-all` fails immediately with `context canceled` | Handler started a goroutine with `c.Request.Context()`, which Gin cancels as soon as the response is written | Use `context.WithoutCancel(c.Request.Context())` for work that outlives the request | Never pass a request context to a goroutine that outlives the response — detach it (`context.WithoutCancel`) or use a fresh context |
| 2026-10-19 | Internet import fails with "Could not find a downloadable source" | Runtime image installed `ffmpeg` but not `yt-dlp`/`node`, which the resolver and downloader exec; failures were only logged at Debug | Added `nodejs yt-dlp` to both Dockerfiles; log resolver failures at Warn | A binary the code shells out to must be installed in the runtime image, and its absence must be visible in logs |
| 2026-10-19 | Downloads work locally but not in containers | `DownloadService.Download` hardcoded the author's `~/.local/bin/yt-dlp` for the metadata call | Use `yt-dlp` from PATH | Never hardcode a user-specific binary path; rely on PATH or config |
| 2026-10-21 | Admin import search sometimes fails with `musicbrainz decode: json: cannot unmarshal string into ... isrcs` | MusicBrainz returns `isrcs` as an array of strings, but the struct modelled it as `[]struct{ISRC string}` | Changed to `ISRCs []string` | Check the real API shape before modelling a nested array; a decode error on one provider can kill the whole search |
| 2026-10-21 | Admin pages request `/admin/music.ico` → 404 | `index.html` used a relative favicon `./music.ico`, which resolves against the current route on nested paths | Use the absolute `/music.ico` | Assets referenced with a relative path break on any nested route |
| 2026-10-21 | Import result card never rendered; page showed `Incorrect locale information provided` | Headless/webview Chromium reported `navigator.language = "en-US@posix"`, and `new Intl.NumberFormat()` throws on a malformed tag, aborting the render | Wrap `Intl.NumberFormat` in a helper that falls back to `'en'` on `RangeError` (format.ts, number.ts) | Never pass a raw environment-provided locale tag to `Intl` without validation |
| 2026-10-21 | `docker build` failed for 5 attempts on `apk add` | The Alpine CDN (`dl-cdn.alpinelinux.org`) was intermittently unreachable/DNS-flaky from this network | Keep the cached `apk` layer unchanged and add the self-contained `yt-dlp_musllinux` binary plus Node copied from `node:22-alpine` (libs included) | When a package CDN is flaky, prefer self-contained artifacts from a reachable host over re-running `apk` |
| 2026-10-21 | SPA got `502 Bad Gateway` on every `/api` call after the api container restarted | nginx resolves a literal `proxy_pass http://api:8080;` **once at startup** and keeps the old container IP | Use a variable (`set $api_upstream http://api:8080; proxy_pass $api_upstream;`) plus `resolver 127.0.0.11 valid=10s;` | In Docker, never use a literal hostname in `proxy_pass` — it must be re-resolved at request time |
| 2026-10-21 | Analytics worker failed every minute: `creator_daily_stats_user_id_fkey` violation | The query inserted `tracks.artist_id` into `creator_daily_stats.user_id` (→ `users.id`), but artists are catalog entities with random uuids and no owner column — an artist id is never a user id | Map track → uploader via `ingestion_drafts.uploaded_by` | Before joining two tables on an id, check the FK target of each side; "artist" and "user" are different entities here |
| 2026-10-21 | ML enrichment always failed: `ml lyrics enrichment failed` | The Go enricher called `GET /api/v1/lyrics/jobs` (a list endpoint) but moja-ml-service only exposes `POST /jobs`, `GET /jobs/{id}` and `GET /jobs/by-track/{id}`; the enricher has no track id to query by | Removed the enricher's ML hooks — the lyrics/covers modules already own ML (enqueue + HMAC webhook) | Before adding a second integration for a service, check the existing one; duplicated clients drift from the API they call |
| 2026-10-21 | ML containers could not reach Postgres/Redis, healthcheck always failed | `moja-ml-service/.env` is host-oriented (`localhost:5433`, `localhost:6379`) and the compose healthcheck used `curl`, which is not in the ML image | Compose now overrides the addresses with service names and the image's own python healthcheck is used | Service `.env` files written for a host run must be overridden in compose with container-network addresses |
| 2026-10-21 | `internal/app` test timed out (>3 min) and overwrote the tracked `./api` and `./worker` binaries | The test ran `go build ./cmd/api` / `./cmd/worker` from inside the test, writing 150 MB of executables into the repo root | One `go build -o t.TempDir() ./cmd/api ./cmd/worker` — same check, temp dir, 12 s | A test that shells out to the build tool must not write into the source tree; use `-o` |
