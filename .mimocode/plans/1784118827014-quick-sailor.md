# Fix Color Theme: Light Mode & Dark Mode

## Goal
Fix the theme system so both light and dark modes work correctly across the entire app. The theme CSS variable system in `main.css` is well-designed — the problem is **hardcoded dark-only colors in components** that bypass the token system.

## Strategy

### Key Decisions
1. **Player components** will adapt to light/dark mode (not always dark)
2. **All `#1db954` hardcoded accent colors** → `var(--accent)` so the user's primary color choice is respected
3. **Layouts** must not hardcode `text-white`/`bg-black` — use theme tokens instead
4. **Auth forms** must use semantic CSS variables instead of hardcoded rgba values

### Existing tokens to use (from `main.css`)
| Purpose | Dark value | Light value | CSS Variable |
|---------|-----------|-------------|--------------|
| Text | white 93% | black 90% | `--text-primary` |
| Text secondary | white 60% | black 56% | `--text-secondary` |
| Text muted | white 24% | black 22% | `--text-muted` |
| Surface bg | #08090c | #ffffff | `--surface-0` |
| Surface hover | white 4% | black 2.5% | `--surface-hover` |
| Accent | p-500 | p-500 | `--accent` |
| Border | white 7% | black 8% | `--border-default` |
| Glass bg | white 3% | white 65% | `--glass-bg` |
