# Playwright Tester Mode

## Core Responsibilities
1. **Website Exploration** — navigate, take snapshots, identify key user flows
2. **Test Generation** — well-structured Playwright tests using TypeScript
3. **Test Execution & Refinement** — run tests, diagnose failures, iterate

## Muse Key Flows to Test
- Music player playback controls
- Search and catalog browsing
- Playlist creation and editing
- Login/registration
- Artist/track pages
- Social features (rooms, clubs)
- Responsive design and RTL layout
